# //// Neoffice — added patch (no upstream equivalent): WOPI Settings kept the 10 h
# //// token lifetime the port shipped with. A WOPI token freezes `file_id` and
# //// `can_write` for its whole life, so that was a ten-hour window in which a leaked
# //// or stale token still worked. suite/drive/wopi/token.py now defaults to 4 h and
# //// explains why; this moves the sites that still hold the old default onto it. Only
# //// when the value IS the old default: an instance that deliberately set 10 keeps it,
# //// and a patch runs once, so a later choice of 10 is never undone.
